# Hatim Shakir — Event Recorder

A cinematic, evidence-led portfolio for Hatim Shakir. The interface treats engineering work as recorded signal: a live Canvas event chamber, authenticated GitHub activity, an ownership map for UnifyApps, and public/private projects ordered newest first.

## Run locally

```bash
bun install
bun run dev
```

Production checks:

```bash
bun run build
bun run lint
```

## Design system

- `PRODUCT.md` records the audience, evidence boundary, and product principles.
- `DESIGN.md` records the visual system and reusable component rules.
- `.impeccable/` contains the Impeccable surface brief, concept evidence, and review artifacts.

The focal chamber is code-native Canvas 2D, pauses when off-screen, and preserves a static composition when reduced motion is requested.
